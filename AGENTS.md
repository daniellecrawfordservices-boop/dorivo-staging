# AGENTS.md

## Absolute Rule

The `LeadForm` / `LeadsForm` component is protected.

Never edit, rename, refactor, move, delete, regenerate, or replace this component unless the user explicitly writes:

"You may edit LeadForm."

## Protected Component

Protected component names:

- `LeadForm`
- `LeadsForm`
- `leadsform`

## Rules

Before making any code changes:

1. Check whether the change affects the LeadForm component.
2. If the requested change touches LeadForm, stop and ask the user for confirmation.
3. Do not change imports, props, styling, validation, text, layout, or logic related to LeadForm.
4. Do not replace LeadForm with a newly generated form.
5. Do not “clean up” or “improve” this component automatically.
